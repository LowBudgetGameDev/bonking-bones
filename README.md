# Bonking Bones

A game inspired by the game "Broken Bones" where you must throw a guy off a mountain to deal as much damage as you can. 
This game is the second of a collection where each game is focussed on a letter of the alphabet. 
This game is for the letter "B" and I made the game about ***B**ones*.

Built With: Unity + C#
